STEWARD'S SKILLS — the place he looks.

Drop a Python file here (e.g. weigh.py, measure.py) and Steward finds it and
adds it to what he knows he can do. His built-in abilities — the four-strokes,
place/collect/discard, rehearse, spawn_terminal — are in his body already; this
folder is for the new ones he grows into. Each should prove itself against real
data before it counts, the same way everything else here does.
